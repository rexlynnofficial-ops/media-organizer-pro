# Media Organizer Pro

macOS media offload & organizer for shoots: multi-source / multi-target backup, checksum verification, metadata-based folder planning, duplicate detection, never-overwrite renaming, verified move and reports.

**Source code and docs are in [`media-organizer-pro/`](media-organizer-pro/)** — see its [README](media-organizer-pro/README.md). Run from source with `python3 media_organizer_pro.py`; a prebuilt macOS app is on the Releases page.
